### 1.1 — Modify `docwriter-bootstrap.sh`

**File**: `.github/agents/docwriter-bootstrap.sh`

Current bootstrap creates `.docwriter/` fresh and refuses to run if it already exists. This is correct for per-task artifacts but wrong for the persistent `meta/` directory.

**Changes**:

1. **Split bootstrap into two modes**: "full" (current behavior — fail if exists) and "meta-only" (idempotent — creates `meta/` without touching core artifacts).

2. **Add persistent `meta/` creation** to the full bootstrap:


### 1.3 — Modify bootstrap to handle re-run gracefully

Current bootstrap exits with error if `.docwriter/` exists. For the meta-knowledge system, we need re-bootstrap to preserve `meta/`:

**Option**: Change the guard logic to:
- If `.docwriter/` exists AND `--clean` flag is provided: delete everything EXCEPT `meta/`, then re-create core artifacts
- If `.docwriter/` exists and no flag: exit with current error message
- If `.docwriter/` doesn't exist: full fresh bootstrap (current behavior)

This ensures `meta/` persists across the teardown-and-rebuild cycle that happens between tasks.
